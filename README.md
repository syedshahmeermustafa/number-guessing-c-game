# number-guessing-c-game
A console-based Number Guessing Game developed in C using loops, conditional statements, random number generation, and score tracking.
The program generates a random number between **1 and 100**, and the player gets **20 attempts** to guess it.

## Features

*  Random number generation from 1–100
*  Maximum of 20 attempts per game
*  Hint when the guess is too low
*  Hint when the guess is too high
*  Win and loss tracking
*  Option to play multiple games
*  Basic input validation
*  Score summary after each game

##  Concepts Used

This project helped me practice:

* Variables and data types
* `if`, `else if`, and `else`
* `for` loops
* `do-while` loops
* Logical operators
* `break` and `continue`
* Functions from `stdlib.h`
* Random number generation using `rand()`
* Random seed generation using `srand(time(0))`
* Basic game-state and score management

##  How It Works

1. The player chooses whether to start the game.
2. The program generates a random number between **1 and 100**.
3. The player enters a guess.
4. The program provides a hint:
   * **"Guess higher"** if the guess is too low.
   * **"Guess lower"** if the guess is too high.
5. The player has a maximum of **20 attempts**.
6. The program displays the result and updates the score.
7. The player can choose to play another round.
